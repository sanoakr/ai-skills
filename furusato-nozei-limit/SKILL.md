# ふるさと納税 控除上限額の計算

## 手順

### 1. 入力値を集める（推測しない）

決定通知書（住民税）と確定申告書から、次の値を確認する。不足分はユーザーに質問する。

| 入力 | 取得元 | CLI 引数 |
|------|--------|----------|
| 住民税の課税総所得金額 | 決定通知書 課税標準「総所得」 | `--taxable-sogo` |
| 株式等・先物の分離課税所得（住民税5%） | 確定申告書 / 通知書 | `--separate-5pct` |
| 合計所得金額 | 確定申告書（分離課税を含む） | `--total-income` |
| 調整控除額 | 決定通知書（あれば優先） | `--adjustment` |
| 寄附額 | 台帳の合計（特例控除対象のみ） | `--donation` |

- 年の途中の試算は前年の確定値を使い、**どの年の値か必ず明記**する（前年値は暫定）。
- 台帳 md がある場合は金額列を合計して `--donation` に渡す。合計が表の合計行と一致するか検算する。

### 2. 計算する

```fish
uv run python -I <このスキルのパス>/scripts/calc_limit.py \
  --taxable-sogo 8120000 --separate-5pct 24382000 \
  --total-income 32502000 --donation 245000
```

- 所得税率は既定で「住民税の課税総所得 − 人的控除差調整額（`--rate-adjust`）」から判定する。直接指定は `--income-tax-rate 0.23`。
- 課税所得が税率区分の境界に近いと警告が出る。警告は必ずユーザーに伝える。
- `--income-tax-taxable`（所得税の課税総所得・寄附前）を渡すと、税率区分を跨ぐ場合の所得税の軽減額を厳密に計算する。
- `--json` で機械可読出力。

### 3. 報告する

- 上限額は **千円未満切捨て（`limit_safe`）を推奨値**として示す（自治体ごとの端数処理の差と、返礼品の事後の金額差に備える）。
- 前提（どの年の所得か・調整控除の扱い・所得税率の判定基準）と警告を併記する。
- 寄附額が上限を超える場合は超過額と実質自己負担の増加額を示す。

## 計算式（一次情報で確認済み）

```
特例控除率 = 100% − 10%（基本分）− 所得税の限界税率 × 1.021
特例控除の上限 = (住民税所得割額 − 調整控除) × 20%     ※所得割額は分離課税分を含む
控除上限額 = 特例控除の上限 ÷ 特例控除率 + 2,000円
```

根拠と確認状況は [references/sources.md](references/sources.md) を参照。

## 注意事項

- 本スキルの結果は**目安**。最終判断は決定通知書・各自治体・税理士の案内に従う。
- **合計所得金額が 2,500万円を超えると調整控除は 0 円**（令和3年度分以後）。「通常 2,500円」と固定しない。
- ワンストップ特例は確定申告をする場合は使えない（確定申告に含めて申告する）。
- 住民税の所得割額の20%という上限があるため、上限を超えた寄附は特例控除が頭打ちになり自己負担が増える。
- 令和9年（2027）以降は復興特別所得税率の引下げと防衛特別所得税の新設があるが、合計の係数 1.021 は変わらない（国税庁 No.2260）。年が変わったら `references/sources.md` の確認日を更新して再確認する。
- 先物取引の所得は年ごとの変動が大きい。寄附前に必ず暫定額で試算する。
